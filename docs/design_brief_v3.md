# Murmur 设计 v3 — 立体关系网络

> 沿用前两版 design tokens（奶油底+珊瑚红+墨蓝、思源宋体、暗色模式可切换）。
> 这是一个新顶级页面 / 新底栏 tab，从首页可进入。

## 一句话

把你微信里所有人（私聊 + 群聊出现过的）做成一张**可旋转、可缩放、可点击**的 3D 关系网络。让人**一眼看出**：谁是核心圈、谁是桥梁、谁是孤岛、哪些朋友互相认识。

## 灵感参考

- Obsidian 的 graph view（节点+边+力导向）
- Figma 的 3D 立体感
- Apple Maps 立体地标的轻盈拟物
- VSCode 的关系图（Class-relations.vsix）

### 节点 (Nodes)

每个节点是一个人（私聊或群聊里出现过的 wxid）：
- **大小** = 消息总量 + 线下证据加权
- **颜色** = 关系层级（A=暖橘红 / B=琥珀 / C=墨蓝 / D=灰 / E=浅灰）
- **形状** = 球体；自己是中心一颗稍大的暖白色珍珠
- **位置** = 力导向（关系紧密度决定距离）+ 同社交圈聚类
- **悬停** 显示头像 + 名字 + 关系标签
- **单击** = 选中（节点放大，相邻节点高亮）
- **双击** = 跳到详情（见下）

### 边 (Edges)

两种类型，颜色不同：
- **私聊边**（暖橘红）— 从中心你到每个有 1-on-1 的人；粗细 = 消息数 + 线下证据
- **共群边**（淡墨蓝）— 你的两个朋友共同在某群；粗细 = 共同群数 + 共群里互相 @ 次数

边的细节：
- 鼠标悬停在边上 → 弹小气泡说明（"你和 kevin：3088 条私聊 + 共在 2 个群"）
- 透明度 = 关系强度（弱关系几乎透明）

### 簇 (Clusters)

自动识别社交圈，用半透明的"光晕"包围：
- 每个簇有标签（自动从群名 / 共同朋友推断："大学室友"、"前同事"、"米哈游游戏群"…）
- 用户可重命名簇
- 簇支持折叠（点一下变成单个聚合节点）

### 桥梁人物 (Bridges)

算法识别：连接两个或多个独立簇的人，给特殊高亮（金色描边）。这些人是你**社交资产**，往往是最重要的中间人。

### 孤岛 (Isolated)

完全没有共群朋友、单纯 1-on-1 的人。在外圈用淡虚线连到中心。这些往往是：
- 跨圈结识的（独立朋友）
- 已疏远的（曾经的朋友圈已散）
- 工作型外联

详情面板上的关键新功能：
- **跨场景画像** — 同一个人在私聊和群聊里的双重表现对比（关键洞察）
- **共同社交圈** — 让你看到这个人和你在哪些群里有交集
- **共同朋友** — 你和这个人都认识谁

## 视图切换

右上角 "📊 视图" 按钮切换：

1. **关系网（默认）** — 3D 力导向图
2. **同心圆** — 你在中心，按关系层级分层（A 内圈 → E 外圈）
3. **时间轨道** — X 轴=认识年份，Y 轴=关系深度，看朋友们的"轨道"
4. **群聊视角** — 节点变成群，看你参与的所有群

## 技术细节（给开发参考）

### 库
- 用 `react-force-graph-3d` 或 `react-force-graph-2d`（轻量，已有现成 React 组件）
- 备选：`d3-force-3d` + `react-three-fiber`（更可控但工作量大）

### 数据
后端给一个 endpoint：

```json
GET /api/graph
{
  "nodes": [
    { "id": "self", "name": "你", "is_self": true, "size": 100 },
    { "id": "wxid_kev", "name": "kevin", "tier": "B", "size": 78,
      "private_msgs": 3088, "group_msgs": 847, "longevity_years": 1 }
  ],
  "edges": [
    { "source": "self", "target": "wxid_kev", "type": "private",
      "weight": 3088, "offline_evidence": 97 },
    { "source": "wxid_kev", "target": "wxid_ash", "type": "co_group",
      "shared_groups": ["米哈游游戏群"], "weight": 0.4 }
  ],
  "clusters": [
    { "id": "g1", "label": "米哈游游戏群", "members": ["self", "wxid_kev", ...] }
  ],
  "stats": { "total_people": 261, "total_edges": 1047, "bridges": 2, "isolates": 23 }
}
```

### 性能
- 261 节点的图很小，react-force-graph 单帧 60fps 没问题
- 如果未来到几千节点，加 LOD（远处节点不渲染细节）

## 视觉

- **背景**: 暗色模式时是夜空感（深墨蓝渐变 + 轻微星点）
- **节点高光**: 选中时有暖橘红柔光
- **边动画**: 加载时从你（self）向外扩展波纹
- **微动效**: 缓慢自旋（0.05 rad/s），让画面有生命感
- **暗色模式**: 必须有，深夜浏览自己的关系网络是最 powerful 的体验
