# Murmur v0.2.17

## 下载

Windows 用户：

- 推荐下载：`Murmur_0.2.17_x64-setup.exe`
- 备用：`Murmur_0.2.17_x64_en-US.msi`

Mac 用户：参见 v0.2.15 release notes。Mac 包待之后用 Apple Silicon 机器构建后补上。

## 这版重点（在 v0.2.16 之上）

四个 onboarding UX 防呆：

- **扫描结果二次过滤**：以前任何**叫 `xwechat_files`** 的目录都会出现在「找到 N 个候选」列表里，包括用户从老版本搬过家留下的空壳目录。0.2.17 现在只把"里面真有 `wxid_*/db_storage`"的候选报上来 —— 检查 1-2 层（覆盖 4.x 双层嵌套），开销可忽略。
- **扫完 0 个候选时主动建议手动输入**：UI 直接列出可能原因（"装的是企业微信"、"数据藏在 Windows / node_modules 等剪枝目录"），并放一个明显的「手动输入路径」按钮兜底。之前只有一行"未找到"小字。
- **「重新扫描」按钮**：扫描完成 / 失败页面新增此按钮，无需返回再点进来 —— 同时按钮在保存某候选时 disable，避免误操作。
- **进度文字更明确**：扫描中标题从「正在扫描 (1/2 个盘已完成)」改成「🔎 扫描中 — 1/2 个盘完成」，下面加一行「⏱ 还在扫，请等所有盘都标记完成再下结论 — 找到的候选会陆续出现在下面」。0.2.16 用户实测时一开始看到 1/2 盘扫完了 0 候选就以为失败，改为重扫才发现是早。
