# Murmur 设计补充 brief — 三个新页面

> 这是对前一份 design brief 的补充。沿用之前的 design tokens（奶油底+珊瑚红+墨蓝、思源宋体+无衬线、杂志/日记本风、暗色模式可切换）。

## 1. 媒体相册 (Media Gallery)

**位置**：FriendPage 增加顶部 Tab：「故事 (现在的内容) / 相册 / 完整对话」。点「相册」切到这个视图。

**布局**：

```
┌──────────────────────────────────────────────────────────┐
│ 故事 [相册] 完整对话                          🔍 在相册搜    │
│ ─────────────────────────────────────────────────────    │
│                                                          │
│  2026 · 4月  ─────────────────────────────────────       │
│  ┌─────┐ ┌─────┐ ┌─────┐ ┌─────┐                        │
│  │ img │ │ img │ │ img │ │ vid │  (4 列 grid，正方形缩略图) │
│  └─────┘ └─────┘ └─────┘ └─────┘                        │
│  ┌─────┐ ┌─────┐ ┌─────┐ ┌─────┐                        │
│  │ vid │ │ img │ │ img │ │ img │                        │
│  └─────┘ └─────┘ └─────┘ └─────┘                        │
│                                                          │
│  2026 · 3月  ─────────────────────────────────────       │
│  ┌─────┐ ...                                             │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

**细节**：
- 每个缩略图右下角小角标：💬 4 (这张图发送时附带文字几条) / ▶ 0:12 (视频时长)
- 视频缩略图左上角小标签 "视频"
- 悬停显示发送时间 + 是谁发的（你 / 对方）+ 关联消息链接（点击跳完整对话定位）
- 点击 → 全屏 lightbox 模态，左右翻页，按 ← → 浏览
- 顶部右侧搜索框：搜对话上下文（"在我和 X 聊到「火锅」时发的图片"）
- 月份 separator 是细线 + 月份标签，简洁
- 空态：朵小花 + "你和 X 还没有交换过媒体"

│ └───────────────────────────────────────────────────┘    │

```
┌──── Claude Code 正在分析 与 kevin 的关系 ────────────┐
│                                                          │
│ ╭─────────────── 助手发言（流式） ──────────────╮       │
│ │ 我先快速过一遍数据 ...                          │       │
│ │ 看到几个有意思的信号：                          │       │
│ │ - 你们晚上 1-3 点聊得最多                       │       │
│ │ - kevin 主动开聊的次数比你多 50%                │       │
│ │ ...                                              │       │
│ │ [打字光标在这里 ▌闪烁]                         │       │
│ ╰────────────────────────────────────────────────╯       │
│                                                          │
│ 已用时 12s · [打开完整对话] [停止]                       │
└──────────────────────────────────────────────────────────┘
```

**分析完成后**渲染成「**精装分析报告**」卡片：
- 大标题：与 kevin 的关系画像
- 副标题：由 Claude Code · 2026·04·30 · 引用了 80 条消息
- 章节按 prompt 里的 5 部分自然展开（关系定性/互动节奏/关键时刻/人物画像/关系走向）
- 引用的具体消息用引言卡形式嵌入（带时间戳和发送人）
- 底部：[导出 PDF] [拷贝全文] [再来一次] [询问后续问题…]

整体风格保持杂志/日记本感，不是聊天 UI 风格。

## 3. 全局任务 / 进度中心

**位置**：顶部 chrome bar 右侧，"密钥" 按钮旁边，加一个**铃铛图标**。有正在进行的任务时，铃铛上有红色小圆点。

**点击展开**（从顶部下拉的小抽屉，宽 380px）：

```
┌────────── 后台任务 ─────────────────────────┐
│                                              │
│ ▶ 正在解密最新数据         [████████░░] 78%  │
│   12 个数据库 · 已完成 9 个                    │
│                                              │
│ ▶ Claude Code 正在分析 kevin   [█░░░░░░░░] 12% │
│   已读取统计 · 正在挑选样本对话                │
│                                              │
│ ✓ 索引完成（12 分钟前）              [清除]   │
│                                              │
└──────────────────────────────────────────────┘
```

**每个任务条**：
- 左边：任务图标 + 名称
- 中间：进度条（确定百分比时填充，不确定时显示流动条）
- 右边：[取消] 或 [详情]
- 完成的任务变浅灰，5 分钟后自动消失

**长操作清单**（系统会创建任务条的）：
- 解密最新数据（每个 .db 一个进度点）
- 提取微信密钥（三步：杀微信→重启→等登录）
- 提取图片密钥（按 MB 滚动）
- 全量解密图片（按张数）
- Agent 分析（按响应字数）
- 建立媒体索引（按记录数）

**风格要求**：
- 进度条颜色用 `--et-orange`，圆角，无渐变
- 任务条内不要 emoji，用一个小 svg 图标（解密 = 钥匙；agent = 闪电；索引 = 文件夹；密钥 = 锁）
- 任务条悬停时整条微微抬起 + 显示阴影
- 抽屉打开时屏幕其他部分有轻微淡化（10% 黑遮罩，可点击关闭）
