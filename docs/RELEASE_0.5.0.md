# Murmur v0.5.0 — 抓 key 新路径、实时同步、聊天浏览与搜索、界面改版

## 下载

Windows 用户：

- 推荐下载：`Murmur_0.5.0_x64-setup.exe`
- 备用：`Murmur_0.5.0_x64_en-US.msi`

Mac 用户：

- Apple Silicon Mac 下载：`Murmur_macOS_AppleSilicon.dmg`
- 备用排错文件：`Murmur_macOS_AppleSilicon.app.zip`
- 只支持腾讯官网版 WeChat for Mac，不支持 App Store 版。

## 使用前请先读

- **只处理本机、本人的数据。** Murmur 只读取这台电脑上你自己登录的微信留下的聊天记录，解密、索引、分析、搜索全部在本机完成，不上传任何内容。
- **重签名或注入微信有账号风险。** Mac 的重签名、Frida 附加、私有副本注入，以及 Windows 的 hook 注入，都不是腾讯官方支持的用法，可能触发风控、被要求重新登录，甚至限制账号。介意的话可以用「手动粘贴密钥」。

## 这版新增

### 抓 key

- **Frida 实时抓 key（Mac，微信 4.1.9+）**：4.1.9 起密钥不再常驻内存，内存扫描经常一个都抓不到。App 内集成 Frida，在你正常使用微信时截获密钥，界面显示倒计时和已匹配的库数；源码运行时可一键安装 Frida。
- **截获账号口令，一轮拿全所有库**：同时截获 `CCKeyDerivationPBKDF` 的账号口令，在本机按每个库的 salt 用 PBKDF2 派生 key，并逐个 HMAC 校验。口令按账号（wxid）保存。
- **Mac 免 Frida 私有副本**：不装 Frida、不输管理员密码。把微信复制到 `~/.murmur/wechat-copy/`，只对副本重签名并注入只记录加密调用的 `murmur_keycap.dylib`，原版 `/Applications/WeChat.app` 不动；每轮结束自动关掉副本、清掉记录文件，用完可删除副本。
  - 真机结论（微信 4.1.15）：副本和原版**共用同一个 `xwechat_files` 容器**，没有弹跨 App 数据访问授权框，需要在副本里**重新登录一次**，23/23 个库的 key 全部通过 HMAC 校验。
  - 因为共用容器，**用之前必须先完全退出原版微信**；Murmur 检测到原版在运行会拒绝开始。

### 数据

- **实时同步（WAL）**：首页「实时同步」开关。后台定时检查，先做一致性快照，只合并 salt 一致、已提交的 WAL 帧，按库增量解密，新消息几秒内出现；默认关闭。
- **全局搜索**：全部聊天记录建本地 SQLite FTS5 全文索引，增量更新，支持时间范围。
- **语义搜索（可选，默认关闭）**：本地 bge-small-zh ONNX 向量模型（约 24MB，下载时校验 SHA-256），可以「按意思」搜没有固定关键词的内容。
- **聊天浏览**：新的聊天页，按时间往前翻、跳到某一天、从搜索结果直接定位到那条消息；大会话按页读取，不再每页全表扫描。
- **导出增强**：CSV / Markdown / ChatLab 格式，附件策略和导出报告。

### AI

- **本机 agent**：除 Claude Code / Codex 外，新增识别 Gemini CLI、Kimi Code、OpenCode；新 agent 工具权限收紧（Kimi 只能读文件，OpenCode 禁止命令 / 编辑 / 联网），分析包里的好友原文不能借机执行命令。
- **MCP 服务**：`etcli mcp` 以只读方式把联系人、聊天、搜索、关系统计提供给 Claude Code / Codex 等 AI 助手；`--privacy` 下名字、wxid 全程脱敏，报错文本也脱敏。见 [MCP.md](MCP.md)。

### 稳定性与安全

- **错误码与诊断包**：后端统一稳定错误码，前端报错目录直接写出原因和处理办法；「复制诊断信息」不管隐私模式开不开都会脱敏（用户名、wxid、key、手机号、邮箱等）。
- **应用锁**：给 Murmur 设密码，闲置自动上锁；由后端执行，锁定期间数据接口一律返回 `423`。正式版不再开放网页检查器。见 [app-lock.md](app-lock.md)。
- **Host 白名单**：本地服务只接受 Host 为 `127.0.0.1` / `localhost` / `[::1]` 加实际端口的请求，防 DNS 重绑定（`403 HOST_NOT_ALLOWED`）。

### 界面

- **新引导**：步骤条「环境自检 → 数据目录 →（Mac）授权/重签 → 取得密钥 → 解密 → 完成」，每步出错有错误码和处理建议，已完成的步骤可单独重做；Mac 按微信版本推荐抓取方式；抓取进行中锁住步骤条。
- **UI 改版**：语义设计 token 和基础组件、浅色 / 深色 / 跟随系统主题、字体内置；左侧导航 + 统一顶栏 + 设置页；各页面补齐加载骨架、空状态和错误状态（接口失败不再显示成「还没有数据」）；手机宽度不再横向溢出；关系网、账号切换、诊断按钮的颜色全部跟随主题。

## 修复

- 关系网切换 top N 不再重新查库。
- 聊天页：游标里的超大整数返回 400 而不是 500；`create_time` 为负的消息也能正常翻页；建排序索引时内存峰值从约 529MB 降到约 37MB（300 万条，tracemalloc 实测），同一个文件的并发请求只建一次。
- 搜索页：索引建好后的自动重搜不会再覆盖你刚提交的新搜索。
- 日志和诊断脱敏补全；Markdown 导出转义远程图片防追踪。
