# 截图指南

## 录演示前 — 必做

1. 启动 Murmur
2. 右下角找到 **「🔓 隐私模式：关」** 按钮
3. **点一下**变成 **「🔒 隐私模式：开」**
4. 所有朋友名 / 群名 / wxid 都变成 `朋友 AB`、`群 5`、`wxid_1234`

确认右下角是黑色 🔒 状态再开始录。

## 三张核心截图

按 README 顺序：

### 1. `home.png` — 主页
- 进 Murmur，主页 chrome 横条 + top 6 朋友卡片 + 月度热度图
- 全屏截图

### 2. `graph.png` — 关系图
- 点 chrome 上的「🌌 关系网」
- 等 ~3 秒 graph 加载
- 点任意一个 A 级或 B 级朋友 → SidePanel 弹出
- SidePanel 里能看到「重要连线」列表（关键证据）
- 全屏截图

### 3. `friend.png` — 人物档案
- 点首页任一朋友卡片
- 滚动到 SignalsEvidenceCard（离线证据）+ ConnectionsCard（关联朋友）
- 全屏截图

### 可选

- `ai-report.png` — 在朋友档案点「📖 阅读完整报告」
- `yearbook.png` — 朋友档案 ActionDock 点「💑 双人年代记」
- `signals.png` — 首页 chrome 点「📊 表格」，离线信号矩阵
- `edge.png` — 关系图里点任意一条朋友间连线，EdgePanel 弹出含群里互动 / 朋友圈 / 提及

## 输出格式

- 1280×800 或 1440×900
- PNG 无压缩
- 放到 `docs/screenshots/<name>.png`

## 关闭隐私模式

录完别忘了关。再点一下右下角按钮，恢复真名。
