# EchoTrace 重设计 — Claude Design Brief

> 把这整份文件复制到 [claude.ai/design](https://claude.ai/design) 的输入框即可。
> 它已包含产品定位、用户痛点、信息架构、视觉方向、关键页面 wireframe 描述。

---

## 1. 一句话定位

EchoTrace 2.0 是一个**完全本地、零配置**的微信聊天回顾与人际关系分析桌面应用。
"打开应用 → 等 30 秒 → 直接看到自己这些年最常聊的 50 个人和年度朋友报告"。

## 2. 重设计动机（旧版痛点）

旧版（v3.0.2）是工程师风格 UI：

- 6 个左侧栏页面（欢迎 / 聊天 / 数据分析 / 群聊分析 / 导出 / 数据管理 / 设置），新人无所适从
- 必须先去「设置」配置密钥 → 选目录 → 测试连接 → 再去「数据管理」点「批量解密」 → 等几分钟 → 才能去「数据分析」看报告
- 关键术语（密钥、xwechat_files、wxid、批量解密、增量更新、备份模式、实时模式…）对非技术用户全是天书
- 默认配色 + Material 控件，毫无情绪温度——但产品的核心是"回望多年好友"，应该是**温暖怀旧**而不是**冰冷工具**

## 3. 目标用户与情境

- **核心用户**：18-30 岁，微信深度用户，会因「年度回顾」类内容感到触动并分享到朋友圈/小红书的人
- **使用场景**：年底 / 跨年 / 毕业季 / 久未联系的朋友突然想起时，打开看一看
- **二级用户**：开发者 / 重度玩家 — 想用 CLI 喂给 LLM 做关系画像（这部分独立的 etcli 已实现，UI 不需要再做）

## 4. 重设计原则（写在显眼处的设计宪法）

1. **3 步内见到内容**：第一次启动 → 同意隐私 → 看到自己的"年度朋友榜"。中间不允许出现任何配置页面。
2. **术语零暴露**：用户永远不该看到 wxid / xwechat_files / WCDB / 解密密钥 / 备份模式这些词。后台默默搞定。
3. **情绪先于功能**：每个核心页面都应该有一句**走心**的标题文案，而不是"会话列表"、"统计数据"这种功能名。
4. **失败也优雅**：如果自动检测密钥失败，给出一个「我来帮你」的引导式弹窗（带视频/动图），不要直接抛错误。
5. **导出是个动作，不是个页面**：把"导出"做成单条对话的右键操作，而不是一个独立的复杂页面。

## 5. 信息架构（从 7 个页面砍到 4 个）

```
┌─ 首页 (我的朋友圈年代记)
│   ├─ 顶部 hero：今年最常聊的 5 个人 + 一句温暖文案
│   ├─ 朋友榜 grid (按总消息数排序，头像+名字+最近活跃)
│   └─ 时光线 (按月份的消息热度图)
│
├─ 单人页 (点朋友头像进入)
│   ├─ 一段「关系小传」(自动生成的一句话总结)
│   ├─ 互动节奏图 (谁更主动、聊天时段分布)
│   ├─ 难忘瞬间 (自动挑出的有信息量的对话片段)
│   └─ 完整聊天记录 (默认折叠，按需展开)
│
├─ 双人合影 (从单人页可发起：选 1 个好友生成双人年度报告)
│
└─ 设置 (只藏 3 项：导出位置、数据目录、清除/重新导入。其他全自动)
```

**移除**：群聊分析、独立导出页、数据管理页、欢迎页。前两个并入"朋友榜筛选 tab"，后两个变隐式后台行为。

## 6. 启动流程（这是重设计的核心）

```
[首次启动]
  ↓
隐私协议 (一屏，不再是设置弹窗)
  ↓
检测中… (一屏 loading 动画 + 友好文案)
  │  └ 自动找 xwechat_files
  │  └ 自动从注册表/进程拿密钥
  │  └ 自动批量解密
  │  └ 全程显示进度，但不显示技术细节
  ↓
首页 (你今年和谁聊得最多 ❤️)
```

**关键**：以前用户要手动点 "测试连接 → 自动检测 → 选 wxid → 保存配置 → 跳到数据管理 → 批量解密"。现在这一切应该是**首次启动时一气呵成的后台流水线**，用户唯一的操作是同意隐私。

## 7. 视觉方向

- **基调**：温暖怀旧，但不土。参考：Spotify Wrapped 的 mood、苹果"回忆"功能、即刻 App 的年度报告
- **主色**：奶油白底 + 暖橘红 (#FF6B47) 主色 + 深墨蓝 (#1A2B4A) 辅色。**不要**微信绿。
- **字体**：标题用衬线 (思源宋体 / Noto Serif SC) 营造"日记感"，正文用无衬线 (PingFang / 思源黑)
- **元素**：圆角大、阴影柔。卡片之间留白多。
- **插画**：手绘风格的微小装饰元素 (信纸、邮票、小书签)，不要 emoji 大乱炖
- **暗色模式**：必须有 — 深夜回顾老朋友是核心使用情境

```markdown
- ...（约 60-80 条按头/中/尾分布的真实消息）

## ⬇️ 把上面整份资料 + 下面这段提示词复制粘贴给 AI
```（内嵌一段定制 prompt）```
```

**为什么是这种设计**：
- 用户的真实痛点不是"Claude Code 用不来"，而是"不知道怎么向 AI 描述自己的需求"。这个设计**把数据 + prompt 一起打包**，用户连提示词都不用想。
- 选 AI 类型那一步，**仅用于微调 prompt 措辞**（豆包/文心更接受中文俚语，ChatGPT/Claude 更适合复杂指令）—— 后端逻辑大同小异。
- 不强迫用户在线传输数据 — 全程本地生成 `.md`，发不发给 AI、发给哪个 AI 都由用户自己决定。这与 EchoTrace 「完全本地」的核心承诺一致。
